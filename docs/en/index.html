VietTelex (ViệtTelex) is a free, open-source Telex and VNI input method for iPhone, Android, macOS, Windows and Linux: fast, light, and correct in every app.

Why VietTelex?

One way to type on every device: phone or computer, the same keys give the same text.

MinimalistInstall and type. Advanced options are there when you need them.
IntuitiveBehaves like a system keyboard — nothing to relearn.
Performant~130 ns per key (measured on a Mac) — smooth however fast you type.

● A real system keyboard

Built into iOS, Android, macOS, Windows and Linux — not a key-blocking app.

● Telex and VNI

Free tone placement, spell-check while typing, text shortcuts.

● Smart with English & code

Keeps google, github, JavaScript… free of stray tone marks.

● Correct in the hard places

Terminals, browser address bars, Excel, Word.

● Complete on phones

Suggestions, swipe typing, templates, clipboard, emoji, themes.

● Light & private

Collects nothing you type, no ads, no tracking. Details.

Install in a minute

Pick your platform to download and see step-by-step instructions.

iPhone & iPad →

Get it on the App Store, then add VietTelex in Settings → Keyboard. iOS 16 or later.

Android →

Install from Google Play or the APK, open the app and tap Enable VietTelex. Android 8 or later.

macOS →

Download the signed .pkg or install with Homebrew, then add ViệtTelex in Input Sources. macOS 13 or later.

Windows →

Install from the Microsoft Store or the .msi and start typing. Portable build available. Windows 10 / 11.

Linux →

One command to install. Ubuntu, Debian, Fedora, Arch; Fcitx5 or IBus.
