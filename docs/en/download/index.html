ViệtTelex for iPhone & iPad

A Telex/VNI Vietnamese keyboard with word suggestions, swipe typing, snippets and clipboard.

  • iOS / iPadOS 16 or later
  • Free
  • Runs entirely on device

After installing

  1. Settings → General → Keyboard → Keyboards → Add New Keyboard… → VietTelex.
  2. While typing, tap 🌐 to switch to VietTelex. Try it in the app: vieejt → việt.
  3. Optional: turn on Allow Full Access for haptics, VietTelex's own key sounds, the Paste button and clipboard history. Typing Vietnamese doesn't need it.

ViệtTelex for Android

Google Play

A Telex/VNI keyboard for phones, tablets and Chromebooks.

⬇︎ Download APK 1.5.1
  • Android 8.0 or later
  • Free
  • Auto-updates via Google Play

After installing

  1. Tap Install on Google Play (or open the .apk if you downloaded it; if asked, allow install unknown apps).
  2. Open the VietTelex app → Enable VietTelex (Settings → System → Languages & input → On-screen keyboard), then Choose VietTelex.
  3. The “may be able to collect all the text you type” warning is Android's generic notice for every third-party keyboard — VietTelex runs entirely on your device.

The Google Play version updates itself; update the APK by installing a newer one over it. All Android releases · Full guide →

A native InputMethodKit input method: no underline, works in Terminal, iTerm and Chrome.

⬇︎ Download VietTelex.pkg
  • macOS 13 Ventura or later
  • Apple Silicon & Intel
  • Signed & notarized by Apple

Other ways

Homebrew

brew install --cask ptrinh/viettelex/viettelex

Update with brew upgrade.

One Terminal command

curl -fsSL https://viettelex.com/install.sh | bash

Uses Homebrew when present; otherwise downloads the .pkg, checks Apple's signature and installs it. Read the script.

Install through one channel only (.pkg or Homebrew) — both manage ~/Library/Input Methods/VietTelex.app.

After installing

  1. System Settings → Keyboard → Input Sources → Edit… → ＋ → Vietnamese → ViệtTelex → Add (the installer opens this for you).
  2. To type in Terminal/iTerm/Chrome: Privacy & Security → Accessibility (macOS 26 and earlier) / Device Control and Data Access (macOS 27) → enable VietTelex.
  3. Switch Vietnamese/English with 🌐 or ⌃Space. Settings: the Vᴛ icon in the menu bar → Settings….

ViệtTelex for Windows

version …

A system Vietnamese keyboard (TSF) — pick it with Win+Space.

Or download the .msi installer directly:

⬇︎ Download x64 (.msi) ⬇︎ Download ARM64 (.msi)
  • Windows 10 (1903) or 11
  • Auto-updates via Microsoft Store
  • Signed installer
  • No restart needed

Downloading the .msi: which one?

Microsoft Store picks the right build for you. For the .msi: x64 for Intel/AMD PCs (most). ARM64 for Snapdragon/ARM PCs. Not sure: Settings → System → About → System type.

After installing

  1. Click Get in Microsoft Store (or run the .msi); VietTelex's Settings window opens when it's done.
  2. Pick VietTelex with Win+Space. Not listed? Open VietTelex once from the Start menu.
  3. Upgrading: Microsoft Store updates it automatically; with the .msi, install the new version over the old one, or click Check for updates in the app.

ViệtTelex for Linux

version …

Ubuntu 22.04 / 24.04 / 26.04, Debian 12 / 13, Fedora 43 / 44 (including Silverblue, Kinoite, Bazzite, Bluefin), RHEL / Rocky / Alma 9 / 10, Arch and distros based on them (x86_64 / amd64, ARM64). Paste into a terminal:

curl -fsSL https://viettelex.com/install.sh | bash

It detects your distro, adds the signed repository (APT, DNF or pacman; on Fedora Atomic it layers with rpm-ostree and needs a reboot), installs VietTelex (Fcitx5 by default; asks if you use IBus) and opens the setup guide. Run it again to update. Options: | bash -s -- --ibus (keep IBus) · --uninstall · --dry-run (show the steps only). Read the script before running it.

Fcitx5 or IBus?

Fcitx5 (recommended, the installer's default): smoother, fewer glitches in Chrome/Electron/terminals; the first time you need to log out and back in once. IBus is Ubuntu/GNOME's default — use --ibus to keep it.

Other ways

Add the APT repository manually 
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/viettelex.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/viettelex.sources >/dev/null <<EOF
Types: deb
URIs: https://ptrinh.github.io/viettelex-apt/
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: main
Signed-By: /etc/apt/keyrings/viettelex.gpg
EOF
sudo apt update
sudo apt install viettelex-fcitx5   # or: sudo apt install viettelex-ibus

From then on it updates like any other package: sudo apt upgrade.

Fedora / RHEL / Rocky / Alma: add the DNF repository manually 
sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-viettelex \
  https://ptrinh.github.io/viettelex-apt/rpm/RPM-GPG-KEY-viettelex
sudo curl -fsSLo /etc/yum.repos.d/viettelex.repo \
  https://ptrinh.github.io/viettelex-apt/rpm/viettelex-fedora.repo   # RHEL/Rocky/Alma: viettelex-el9.repo or viettelex-el10.repo
sudo dnf install viettelex viettelex-fcitx5   # RHEL/Rocky/Alma, or to keep IBus: viettelex-ibus

Updates: sudo dnf upgrade. RHEL/Rocky/Alma ship IBus only (EPEL has no Fcitx5). Fedora Atomic: use the one-line command above (rpm-ostree), or see RPM.md.

Arch / Manjaro / EndeavourOS / CachyOS: pacman repository 
curl -fsSLO https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg
sudo pacman-key --add viettelex-archive-keyring.gpg
sudo pacman-key --lsign-key 43ADE236BCC43900B8F146B4F57C885055149990
printf '\n[viettelex]\nSigLevel = Required DatabaseRequired\nServer = https://ptrinh.github.io/viettelex-apt/arch/$arch\n' \
  | sudo tee -a /etc/pacman.conf >/dev/null
sudo pacman -Sy viettelex

Updates: sudo pacman -Syu. The AUR package viettelex-bin comes later (AUR registration is closed for now). Details: ARCH.md.

Manual download (.deb) with SHA256

Pick your series (~jammy1 = 22.04, ~noble1 = 24.04) and architecture (amd64 = Intel/AMD, arm64 = ARM), then run sudo apt install ./*.deb. This route does not update through apt; the app's “Check for updates” button still updates it.

ViệtTelex for websites

JavaScript SDK · 1.0.0

Embed Telex/VNI Vietnamese typing in any web page or web app — the same WebAssembly engine as the ViệtTelex apps (100% match on the 358,017-case test corpus). No network, no storage.

npm i @viettelex/core
npm: @viettelex/core Docs on GitHub Demo source
  • MIT licensed
  • input, textarea, contenteditable
  • Zero dependencies

Attach to a text field

No bundler needed — load it straight from the CDN:

<textarea id="note"></textarea>
<script type="module">
  import { attach } from 'https://cdn.jsdelivr.net/npm/@viettelex/core@1/dist/viettelex.mjs';
  const vt = await attach(document.getElementById('note'));
  // vt.setEnabled(false) · vt.setOptions({ inputMethod: 'vni' }) · vt() to detach
</script>

With a bundler: import { attach } from '@viettelex/core'. Ctrl+Space toggles Vietnamese/English; password/email/number/tel fields stay literal; the SDK steps aside when the device already has a Vietnamese input method (UniKey, EVKey, the OS IME…). Custom editors, canvas, games: use createEngine().

Pick a build

Buildimportgzip
Full, single file (default)@viettelex/core28.1 KB
Lite, single file@viettelex/core/lite17.0 KB
Full, separate .wasm@viettelex/core/external1.8 + 20.3 KB
Lite, separate .wasm@viettelex/core/lite/external1.8 + 11.2 KB

Every build adds the SDK's JS (~5.9 KB gzip). Lite drops the English dictionaries: it keeps Telex/VNI, the syllable validator and rule-based auto-restore (google, github) and differs only on dictionary words (he is → “he í”). Separate .wasm builds let a CDN/browser cache the engine long-term.
