ViệtTelex cho iPhone & iPad

Bàn phím tiếng Việt Telex/VNI với gợi ý từ, gõ vuốt, mẫu câu, clipboard.

  • iOS / iPadOS 16 trở lên
  • Miễn phí
  • Chạy hoàn toàn trên máy

Sau khi cài

  1. Cài đặt → Cài đặt chung → Bàn phím → Bàn phím → Thêm bàn phím mới… → VietTelex.
  2. Khi gõ, bấm 🌐 để chuyển sang VietTelex. Thử trong app: vieejt → việt.
  3. Tuỳ chọn: bật Cho phép truy cập đầy đủ (Full Access) nếu muốn dùng rung phản hồi, âm phím riêng, nút Dán và lịch sử clipboard. Gõ tiếng Việt không cần quyền này.

ViệtTelex cho Android

Google Play

Bàn phím Telex/VNI cho điện thoại, máy tính bảng và Chromebook.

⬇︎ Tải APK 1.5.1
  • Android 8.0 trở lên
  • Miễn phí
  • Tự cập nhật qua Google Play

Sau khi cài

  1. Bấm Cài đặt trên Google Play (hoặc mở file .apk nếu tải APK; máy hỏi thì cho phép cài ứng dụng không rõ nguồn gốc).
  2. Mở app VietTelex → bấm Bật VietTelex (Cài đặt → Hệ thống → Ngôn ngữ & nhập liệu → Bàn phím trên màn hình), rồi Chọn VietTelex.
  3. Cảnh báo “có thể thu thập mọi văn bản bạn nhập” là cảnh báo chung của Android cho mọi bàn phím bên thứ ba — VietTelex chạy hoàn toàn trên máy.

Bản Google Play tự cập nhật; bản APK cập nhật bằng cách tải bản mới và cài đè. Mọi bản Android · Hướng dẫn chi tiết →

ViệtTelex cho macOS

phiên bản …

Bộ gõ chuẩn InputMethodKit: không gạch chân, gõ được trong Terminal, iTerm, Chrome.

⬇︎ Tải VietTelex.pkg
  • macOS 13 Ventura trở lên
  • Apple Silicon & Intel
  • Apple ký & notarize

Cách khác

Homebrew

brew install --cask ptrinh/viettelex/viettelex

Cập nhật bằng brew upgrade.

Một lệnh trong Terminal

curl -fsSL https://viettelex.com/install.sh | bash

Có Homebrew thì dùng Homebrew; không thì tải .pkg, kiểm chữ ký Apple rồi cài. Xem script.

Chỉ cài qua một kênh (.pkg hoặc Homebrew) — cả hai cùng quản lý ~/Library/Input Methods/VietTelex.app.

Sau khi cài

  1. System Settings → Keyboard → Input Sources → Edit… → ＋ → Vietnamese → ViệtTelex → Add (trình cài tự mở sẵn trang này).
  2. Để gõ trong Terminal/iTerm/Chrome: Privacy & Security → Accessibility (macOS 26 trở về trước) / Device Control and Data Access (macOS 27) → bật VietTelex.
  3. Chuyển Việt/Anh bằng 🌐 hoặc ⌃Space. Cài đặt: biểu tượng Vᴛ trên thanh menu → Cài đặt….

ViệtTelex cho Windows

phiên bản …

Bàn phím tiếng Việt của hệ thống (TSF) — chọn bằng Win+Space.

Hoặc tải bộ cài .msi trực tiếp:

⬇︎ Tải bản x64 (.msi) ⬇︎ Tải bản ARM64 (.msi)
  • Windows 10 (1903) hoặc 11
  • Tự cập nhật qua Microsoft Store
  • Bộ cài đã ký số
  • Không cần khởi động lại

Tải .msi: chọn bản nào?

Microsoft Store tự chọn đúng bản. Nếu tải .msi: x64 cho máy Intel/AMD (đa số). ARM64 cho máy Snapdragon/ARM. Không chắc: Cài đặt → Hệ thống → Giới thiệu → Loại hệ thống.

Sau khi cài

  1. Bấm Tải trong Microsoft Store (hoặc chạy file .msi); cửa sổ Cài đặt của VietTelex tự mở.
  2. Chọn VietTelex bằng Win+Space. Không thấy? Mở VietTelex một lần từ menu Start.
  3. Nâng cấp: Microsoft Store tự cập nhật; bản .msi thì cài bản mới đè lên, hoặc bấm Kiểm tra cập nhật trong app.

ViệtTelex cho Linux

phiên bản …

Ubuntu 22.04 / 24.04 / 26.04, Debian 12 / 13, Fedora 43 / 44 (cả Silverblue, Kinoite, Bazzite, Bluefin), RHEL / Rocky / Alma 9 / 10, Arch và bản dựa trên chúng (x86_64 / amd64, ARM64). Dán vào Terminal:

curl -fsSL https://viettelex.com/install.sh | bash

Lệnh tự nhận distro, thêm kho đã ký (APT, DNF hoặc pacman; Fedora Atomic: rpm-ostree, cần khởi động lại), cài VietTelex (Fcitx5 mặc định, hỏi nếu máy đang dùng IBus) và mở hướng dẫn bật bộ gõ. Chạy lại = cập nhật. Tuỳ chọn: | bash -s -- --ibus (giữ IBus) · --uninstall (gỡ) · --dry-run (chỉ xem các bước). Xem mã script trước khi chạy.

Fcitx5 hay IBus?

Fcitx5 (khuyên dùng, mặc định của lệnh cài): gõ mượt hơn, ít lỗi hơn trong Chrome/Electron/terminal; lần đầu cần đăng xuất/đăng nhập một lần. IBus là mặc định của Ubuntu/GNOME — chọn --ibus nếu muốn giữ nguyên.

Cách khác

Thêm kho APT thủ công 
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/viettelex.gpg >/dev/null
sudo tee /etc/apt/sources.list.d/viettelex.sources >/dev/null <<EOF
Types: deb
URIs: https://ptrinh.github.io/viettelex-apt/
Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
Components: main
Signed-By: /etc/apt/keyrings/viettelex.gpg
EOF
sudo apt update
sudo apt install viettelex-fcitx5   # hoặc: sudo apt install viettelex-ibus

Sau đó cập nhật như mọi gói khác: sudo apt upgrade.

Fedora / RHEL / Rocky / Alma: thêm kho DNF thủ công 
sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-viettelex \
  https://ptrinh.github.io/viettelex-apt/rpm/RPM-GPG-KEY-viettelex
sudo curl -fsSLo /etc/yum.repos.d/viettelex.repo \
  https://ptrinh.github.io/viettelex-apt/rpm/viettelex-fedora.repo   # RHEL/Rocky/Alma: viettelex-el9.repo hoặc viettelex-el10.repo
sudo dnf install viettelex viettelex-fcitx5   # RHEL/Rocky/Alma, hoặc giữ IBus: viettelex-ibus

Cập nhật: sudo dnf upgrade. RHEL/Rocky/Alma chỉ có IBus (EPEL chưa có Fcitx5). Fedora Atomic: dùng lệnh một dòng ở trên (rpm-ostree), hoặc xem RPM.md.

Arch / Manjaro / EndeavourOS / CachyOS: kho pacman 
curl -fsSLO https://ptrinh.github.io/viettelex-apt/viettelex-archive-keyring.gpg
sudo pacman-key --add viettelex-archive-keyring.gpg
sudo pacman-key --lsign-key 43ADE236BCC43900B8F146B4F57C885055149990
printf '\n[viettelex]\nSigLevel = Required DatabaseRequired\nServer = https://ptrinh.github.io/viettelex-apt/arch/$arch\n' \
  | sudo tee -a /etc/pacman.conf >/dev/null
sudo pacman -Sy viettelex

Cập nhật: sudo pacman -Syu. Gói AUR viettelex-bin sẽ có sau (AUR đang tạm đóng đăng ký). Chi tiết: ARCH.md.

Tải thủ công (.deb) kèm SHA256

Chọn đúng series (~jammy1 = 22.04, ~noble1 = 24.04) và kiến trúc (amd64 = Intel/AMD, arm64 = ARM), rồi sudo apt install ./*.deb. Cách này không tự cập nhật qua apt — nút “Kiểm tra cập nhật” trong app vẫn cập nhật được.

Đang tải danh sách…

Sau khi cài

  1. Mở VietTelex trong menu ứng dụng (hoặc viettelex-settings --onboarding) và làm theo hướng dẫn.
  2. Fcitx5: đăng nhập lại một lần rồi bấm Thêm. IBus (GNOME): Cài đặt → Bàn phím → Nguồn nhập → + → Tiếng Việt → VietTelex.
  3. Chuyển Việt/Anh: Ctrl+Space.

ViệtTelex cho website

JavaScript SDK · 1.0.0

Nhúng bộ gõ Telex/VNI vào trang web hoặc web app — cùng engine WebAssembly với các app ViệtTelex (khớp 100% bộ kiểm thử 358.017 ca). Không mạng, không lưu dữ liệu.

npm i @viettelex/core
npm: @viettelex/core Tài liệu trên GitHub Mã demo
  • Giấy phép MIT
  • input, textarea, contenteditable
  • Không phụ thuộc thư viện nào

Gắn vào ô nhập

Không cần bundler — nạp thẳng từ CDN:

<textarea id="note"></textarea>
<script type="module">
  import { attach } from 'https://cdn.jsdelivr.net/npm/@viettelex/core@1/dist/viettelex.mjs';
  const vt = await attach(document.getElementById('note'));
  // vt.setEnabled(false) · vt.setOptions({ inputMethod: 'vni' }) · vt() để gỡ
</script>

Có bundler: import { attach } from '@viettelex/core'. Ctrl+Space chuyển Việt/Anh; ô password/email/number/tel luôn gõ thường; SDK tự nhường khi máy đã có bộ gõ tiếng Việt khác (UniKey, EVKey, bộ gõ hệ thống…). Editor riêng, canvas, game: dùng createEngine().
